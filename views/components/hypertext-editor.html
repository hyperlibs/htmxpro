Hypertext Editor

A zero-bloat, Notion-grade WYSIWYG document editor with inline resizable HyperSheet tables, 2D arrow key navigation, Alt + ↑/↓/←/→ row & column splitters, document right-click context menu, and Levenshtein auto-fix spellchecker.

Welcome to Hypertext Editor

Hypertext Editor is an ultra-lean, hypermedia-driven rich text suite designed for modern web applications. It replaces heavy WYSIWYG packages with zero external dependencies.

💡 ProTip: Type / on any empty line for slash commands, or Right-Click anywhere for the document context menu!

Inline Resizable HyperSheet Table

Navigate cells with ↑ / ↓ / ← / →. Press Alt + ↓ to add a row below, or Alt + → to add a column. Drag column & row border handles to resize.

HTMX Form Integration

Hypertext Editor connects directly to standard HTMX forms. It updates a hidden content_html payload on every change. 

<!-- HTMX Form Submission -->
<form hx-post="/api/posts/create" hx-target="#post-feedback" class="space-y-4">
  <input type="text" name="title" placeholder="Post Title..." class="w-full px-4 py-2 border rounded-lg">
  
  <!-- Drop-in Hypertext Editor -->
  <div hx-ext="reactive" ...>
    <input type="hidden" name="content_html" id="hypertext-hidden-input">
  </div>

  <button type="submit" class="px-5 py-2.5 rounded-lg bg-primary text-primary-foreground font-semibold">
    Publish Article →
  </button>
</form>

Go DSL Usage

import "github.com/hyperlibs/HTMX PRO/go/components"

// Server-rendered Hypertext Editor with inline HyperSheet table
editor := components.HypertextEditor(components.HypertextEditorProps{
    Name:        "article_body",
    Placeholder: "Write your document...",
    InitialHTML: "<h1>My Notes</h1><p>Start writing here...</p>",
    MinHeight:   "350px",
})
